ระบบบริหารการลางาน โรงพยาบาลภักดีชุมพล
============================================================

URL หลัก
http://localhost/Wedphakdee/repair_form/leave/index.php

ติดตั้ง / อัปเดตฐานข้อมูลครั้งแรก (Admin)
http://localhost/Wedphakdee/repair_form/leave/install.php

ฟังก์ชันหลัก
- Dashboard สิทธิ์วันลาคงเหลือ + สรุปครั้ง/วันตามปีงบประมาณ
- ประเภทการลา 8 ประเภท: ลากิจ, ลาพักผ่อน, ลาป่วย, ลาศึกษา/อบรม,
  ลาทหาร, ลาช่วยคลอด, ลาประกอบพิธีทางศาสนา, ลาติดตามคู่สมรส
- ยื่นใบลา / แก้ไขใบลา / แนบใบรับรองแพทย์และเอกสารประกอบ
- ผู้ใช้ทั่วไปแก้ไขใบลาของตนเองได้ในช่วงรอดำเนินการ แต่ลบไม่ได้
- Admin เท่านั้นที่ลบข้อมูลใบลาได้
- Workflow 2 ขั้น: เพื่อนร่วมงานรับมอบงาน -> หัวหน้างานเห็นชอบ/อนุมัติ
- ฐานข้อมูลหัวหน้างานแยกตามหน่วยงาน
- ระบบแจ้งยกเลิกและให้หัวหน้างาน/Admin ยืนยันยกเลิก
- เมนูรับมอบงานจากผู้ใช้รายอื่น
- ปฏิทินการลาแบบรายเดือน กรองตามหน่วยงาน
- ตั้งค่าโควตาเริ่มต้นและสิทธิ์วันลารายบุคคลตามปีงบประมาณ
- Audit log ประวัติการทำรายการ
- CSRF protection / Prepared statements / ตรวจสิทธิ์ฝั่ง PHP
- Responsive รองรับมือถือ

ตารางฐานข้อมูลใหม่
- leave_types_master
- leave_supervisors
- leave_applications
- leave_balances
- leave_audit_logs

หมายเหตุเรื่องสิทธิ์วันลา
ค่าโควตาในระบบเป็นค่าเริ่มต้นสำหรับการตั้งค่าระบบเท่านั้น
Admin ควรปรับให้ตรงกับระเบียบ/สิทธิ์จริงของโรงพยาบาลในเมนู "สิทธิ์วันลา"
