ระบบข้อมูลอาชีพบุคลากร - โรงพยาบาลภักดีชุมพล

ติดตั้ง:
1. นำโฟลเดอร์ Wedphakdee ไปทับโปรเจกต์เดิม
2. Login ด้วย Admin
3. เปิด http://localhost/Wedphakdee/repair_form/personnel/install.php
4. กด ติดตั้ง / อัปเดตฐานข้อมูลตอนนี้
5. เปิด career_options.php เพื่อเพิ่ม/แก้ไขตัวเลือก Dropdown
6. เปิด add.php เพื่อเพิ่มบุคลากร

ข้อมูลอาชีพที่เป็น Dropdown:
- กลุ่มงาน
- ฝ่าย / แผนก
- หน่วยงาน (ใช้ตาราง departments เดิม เพื่อเชื่อมระบบอื่น)
- ตำแหน่ง
- ระดับ
- สถานะปัจจุบัน
- กลุ่มข้าราชการ
- ประเภทข้าราชการ
- กลุ่มบุคลากร

ฟิลด์วันที่/ตัวเลข เช่น วันที่บรรจุ เงินเดือน ใช้ input ที่เหมาะสม ไม่ใช้ Dropdown
